Authorization callback

This page exists so that Salesforce has a fixed address to return to after you authorize the extension. Safari gives every installation its own random identifier, which cannot be registered as a Connected App callback URL, so the authorization lands here first.

Nothing is stored or sent anywhere. The page holds no code of its own beyond this text — the extension reads the authorization code straight out of the address bar. The PKCE verifier needed to exchange that code never leaves your browser.

If you reached this page on your own, there is nothing to do here. Open the extension from a Salesforce tab instead.
